# Transport AI — Hotel Boutique Pinar

Demo conceptual de una web boutique con asistente interactivo.

## Requisitos
- Node.js 20.9 o superior
- npm

## Instalar y ejecutar
```bash
npm install
npm run dev
```
Abre http://localhost:3000

## Publicar
Sube todos los archivos a un repositorio de GitHub y conéctalo a Vercel. Vercel detectará Next.js automáticamente.

## Antes de presentar
- Esta es una demo comercial conceptual, no una web oficial del hotel.
- El asistente usa respuestas simuladas en el navegador; no usa una API ni consulta reservas.
- Verifica con el hotel los servicios, políticas, imágenes y datos antes de convertirla en una implementación real.
- Cambia imágenes y textos según los permisos y la información confirmada por el hotel.
